XENEON EDGE Stereo VU Meter 2.9.7 · 로그인 자동 실행

처음 한 번
1. ZIP을 통째로 압축 해제합니다.
2. 이전에 Start-Audio-Bridge.bat로 연 창이 있다면 닫습니다.
3. Enable-Audio-Bridge-Startup.cmd를 실행합니다. 현재 Windows 계정의
   시작프로그램에 등록되고 브리지가 즉시 콘솔 창 없이 대기합니다.
   관리자 권한은 필요 없습니다.
4. iCUE에서 Stereo-VU-Meter.icuewidget을 다시 가져오고
   127.0.0.1:18742 연결 권한을 허용합니다.
   입력 측정을 사용하려면 이번 버전의 브리지와 위젯을 모두 설치합니다.

이후 사용
- Windows 로그인 시 브리지가 자동으로 대기합니다.
- Windows 기본 출력을 DAC에 두고 제논 엣지에서 START를 누릅니다.
- STOP을 누르면 오디오 장치를 해제하고 다음 버튼 요청을 기다립니다.
- 자동 실행 등록과 브리지를 제거하려면 Disable-Audio-Bridge-Startup.cmd를
  실행합니다. iCUE 위젯은 iCUE 위젯 페이지에서 제거할 수 있습니다.

위젯 설정
- VU 미터 테마에서 기본 테마 또는 아날로그를 선택합니다.
- 아날로그 테마는 24개 음역대의 세로 게이지과 오른쪽 원형 L/R 미터를 표시합니다.
- 미디어 표시를 켜면 앨범 커버와 이전 곡, 재생/일시정지, 다음 곡 버튼이
  표시됩니다. 미디어 위치에서 왼쪽 또는 오른쪽을 고릅니다.

- 앨범 아트는 Windows 미디어 세션 이미지가 같은 곡이고 더 선명할 때만
  교체됩니다. 재생 앱이 이미지를 제공하지 않으면 iCUE 이미지가 표시됩니다.

- 재생바는 Windows에 곡의 재생 시간을 제공하는 앱에서 표시됩니다.
  재생 위치 변경을 지원하는 앱에서는 바를 드래그할 수 있습니다.
  이 기능은 새 브리지와 위젯을 함께 설치해야 합니다.

- iCUE 위젯 설정 → VU 미터 → 오디오 소스에서 Windows 기본 출력 또는
  Windows 기본 입력을 선택합니다. 기본 입력 장치는 Windows 소리 설정에서 바꿉니다.
  Windows 마이크 접근 권한이 꺼져 있으면 입력을 읽을 수 없습니다.
